짝 역할 교대

  • 기기 1대를 짝이 함께 써요. 조작자는 화면을 만지고, 설명자는 무엇이 바뀌는지 말해요. 실험 A가 끝나면 역할을 바꿔요.
  • 탐정 회의에서는 A 30초 설명 → B 근거 질문 → 역할 교대. 타이머는 필요할 때만 눌러 쓰고 자동으로 시작하지 않아요.

앱이 일부러 이렇게 동작해요

  • 예상을 저장해야 2~5화면이 열리고, 실험 A를 저장해야 실험 B가 열려요.
  • 조작하기 전에는 규칙이나 정답을 보여 주지 않아요. 원을 직접 조작한 뒤에만 「비교 결과 보기」가 열리고, 기록은 비교 결과를 본 뒤 세 칸을 모두 써야 저장돼요.
  • 틀리면 먼저 질문으로 되묻고, 두 번째에 어디를 볼지 짚어 줘요. 별은 조건을 지키고 이유까지 써야 받아요(속도 경쟁 없음).
  • 보너스 설명은 「반지름·컴퍼스·벌리다·길이·지름」 같은 낱말이 있는지로만 간단히 판단해요. 낱말만 넣어도 통과할 수 있으니 설명 내용은 선생님이 함께 봐 주세요.
  • 화면 길이는 「단위」로 표시해요. 컴퍼스로 그릴 때는 1단위를 1cm로 안내해 주세요.

예상 오개념과 개입

  • 「큰 원을 그리려면 중심도 옮겨야 한다」 → 실험 A에서 중심 잠금 상태로 원이 커지는 것을 확인
  • 「반지름이 1 늘면 지름도 1 는다」 → 지름 보기를 켜고 지름이 2씩 느는 것을 확인
  • 「중심이 같으면 같은 원」 → 물수제비(동심원)를 반례로 제시

수업 전 점검

  • 이 파일 하나(index.html)를 기기에 저장해 브라우저로 열면 인터넷 없이 모든 기능이 작동해요.
  • 학생 이름은 입력하지 않아도 돼요. 기록은 각 기기 브라우저에만 저장되고 외부로 보내지 않아요.
  • 공용 태블릿은 수업 후 「처음부터」 버튼으로 초기화해 주세요.
